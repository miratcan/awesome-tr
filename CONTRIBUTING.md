# Katkıda Bulunma

## Proje Ekleme

1. Bu repoyu fork'layın
2. `README.md`'de uygun kategoriye projenizi ekleyin
3. Pull request açın

## Format

```markdown
- [Proje Adı](https://github.com/kullanici/proje) - Kısa açıklama.
```

## Kurallar

- Proje GitHub'da public olmalı
- Aktif veya kullanılabilir durumda olmalı (arşivlenmiş ama çalışan projeler kabul)
- Açıklama Türkçe, tek cümle
- Uygun kategoriye ekleyin, yeni kategori gerekiyorsa PR açıklamasında belirtin
